# PMIS – Smart Internship Recommendation and Allocation System

A web-based platform for the **Prime Minister Internship Scheme (PMIS)** that connects internship seekers, companies, and administrators.

## Key Features

- **Student:** Registration, login, profile management, internship details, and application tracking.
- **Company:** Registration, login, candidate profile viewing, and candidate management.
- **Admin:** Manage internship seekers, view candidate profiles, manage internship matches, and monitor platform activities.

## Technology Stack

- **Backend:** Python, Flask
- **Frontend:** HTML, CSS, JavaScript
- **Database:** SQLite

## Installation and Setup

**Prerequisites:** Python 3.x and Git.

1. Clone the repository:

```bash
git clone https://github.com/Mayank-1708/PMIS-Smart-Allocation.git
```

2. Open the project directory:

```bash
cd PMIS-Smart-Allocation
```

3. Install dependencies:

```bash
pip install -r requirements.txt
```

4. Run the application:

```bash
python app.py
```

Open the local URL displayed in the terminal.

## Database

The application uses SQLite. The repository includes `database.db` for demonstration purposes.
